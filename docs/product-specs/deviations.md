# Deviations

Where the implementation diverges from `aptos-sp-spec.md`, and why.

This file is **append-only** during the project's lifecycle. Each entry
captures one deviation, dated, with a reason and (when known) the
trigger that would close it.

## Format

```markdown
## YYYY-MM-DD — short title

**Spec says:** quote or paraphrase the relevant spec section.
**Impl does:** what the codebase actually does.
**Why:** the constraint or tradeoff that drove the divergence.
**Closes when:** the condition under which we would re-align.
```
